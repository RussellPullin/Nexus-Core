# Controls Mapping — SOC 2 TSC / ISO 27001 (lightweight)

**Purpose:** Show enterprise buyers how our policies map to common control frameworks.  
**Not a certification.** This is a bridging artefact until SOC 2 / ISO audit.

| Risk / vendors | CC9 | 5.19–5.21 | Vendor Risk · Subprocessors |
| Incident response | CC7 | 5.24–5.28 | Data Breach Response Plan · Logging |
