## Quick start — what to do next

1. Confirm contracting **legal entity + ABN**.  
2. Lawyer-review **Customer Terms**, **DPA**, and **privacy policies**.  
3. Publish website routes using the publishing checklist.  
4. Update App Store privacy / terms / account-deletion URLs.  
5. For large customers: start at [`05-Enterprise-Sales/00-Enterprise-Readiness-Roadmap.md`](05-Enterprise-Sales/00-Enterprise-Readiness-Roadmap.md).  
6. Adopt internal policies via [`06-Internal-Policies/00-Policy-Register.md`](06-Internal-Policies/00-Policy-Register.md) and fill the evidence vault.
