# Enterprise Deal Checklist (pre-signature)

Use before signing a large customer.

## Commercial / legal

- [ ] Contracting entity + ABN confirmed on order form  
- [ ] Customer Terms or negotiated MSA agreed  
- [ ] DPA executed (including breach timelines)  
- [ ] Subprocessor list attached / linked  
- [ ] SLA commitments realistic for current ops  
- [ ] Insurance certificates provided if requested  
- [ ] Pricing / seats / mobile apps clearly scoped (Core vs Shifter vs Pro)  
- [ ] Data residency commitments match actual hosting  

## Security pack sent

- [ ] Trust Center one-pager  
- [ ] Security questionnaire responses (updated)  
- [ ] Security overview  
- [ ] Pen-test summary (if available) under NDA  

## Technical readiness

- [ ] Tenant / project provisioning plan  
- [ ] Admin MFA enabled  
- [ ] Backup/restore confirmed for that environment  
- [ ] Support escalation contacts exchanged  
- [ ] Export/deletion process explained  

## After signature

- [ ] Store signed docs in private vault  
- [ ] Add customer to incident notification list  
- [ ] Schedule QBRs / security review if contracted
