## Who we are

Nexus Core Solutions provides Australian disability-provider operations software:

- **Nexus Core** — web CRM for coordinators and admin  
- **Shifter** — mobile shift, notes, and incident capture for workers  
- **Shifter Pro** — advanced mobile operations including invoicing and field management  

We process customer content (including participant and worker records) **on behalf of provider organisations** under a Data Processing Addendum.

## Security highlights

| Control area | Practice |
|--------------|----------|
| Encryption in transit | TLS/HTTPS for web and APIs |
| Encryption at rest | Cloud-provider managed encryption for primary stores |
| Access control | Role-based access within organisations; least-privilege admin access |
| Hosting | Cloud infrastructure with Australian hosting preferred for customer projects |
| Isolation | Organisation-scoped data access; dedicated projects/instances where deployed that way |
| Backups | Provider-managed backups with periodic restore verification (documented internally) |
| Logging | Operational and security-relevant logs retained for investigation |
| Incident response | Documented breach response aligned to the Australian NDB scheme |
| Subprocessors | Published list; material changes notified under DPA |
| Mobile | Offline-capable apps; customers should enforce device passcodes / org MDM as needed |
